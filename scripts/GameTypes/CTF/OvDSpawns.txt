# OvD attacker starting positions, per base.
#
# Format:   BASE = tileX,tileY
# Comments start with #. A base left blank is simply "not configured yet".
#
# WHAT THIS IS FOR
# At the start of an OvD match the script places both sides:
#   DEFENCE  - the Combat Engineer and Field Medic are dropped onto the base's resource pile
#              (the same coordinate SetupBase spawns the 150 Titanium Oxide stacks on). Those
#              coords come from the `bases` table in CTF.cs, so nothing is needed here for them.
#   OFFENCE  - everyone is warped to that base's ENTRY POINT, which is what this file supplies.
#              e.g. A7 is entered via the A3 elevator, so A7's attacker start is the A3 landing.
#
# A base with no entry configured simply skips the offence warp and says so in the arena, rather
# than dumping the attackers somewhere wrong.
#
# This file is re-read at the START OF EVERY OvD MATCH, so you can fill these in, run a match,
# adjust, and run again without restarting the zone.
#
# Coordinates are TILE coordinates (the same units *setup and the bases table use), not pixels.
# To find one in game: stand where the attackers should start and read your position.
#
# ---------------------------------------------------------------------------------------------
# Base pile coordinates, for reference (where the defence support gets placed):
#
#   A7   pile=(19,463)    A5   pile=(57,369)    B6   pile=(153,445)
#   D7   pile=(277,495)   B8   pile=(147,596)   A8   pile=(22,574)
#   F8   pile=(450,610)   A10  pile=(100,733)   F6   pile=(440,456)
#   F5   pile=(422,370)   H4   pile=(600,280)
#
# ---------------------------------------------------------------------------------------------
# ATTACKER START POSITIONS - fill these in.
#
# Titan-side bases (Titan defends these):
D7 = 319,158

# Collective-side bases (Collective defends these):
